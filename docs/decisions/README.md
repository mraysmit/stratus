# Architecture Decisions

Accepted architecture decision records belong here using `ADR-P<phase>-NNN-short-title.md` names (for example `ADR-P1-001-ceph-baseline.md`). The phase token records when the decision was taken; the decision itself and any artifact it names use stable capability names.
